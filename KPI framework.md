## 2. KPI Framework

To evaluate operational performance, we identify KPIs for the different parts of the company.

| Operational Area | KPI | Purpose |
|---|---|---|
| Sourcing | Raw material stock level | Measure availability of raw materials |
| Sourcing | Raw material stock value | Measure capital tied up in inventory |
| Sourcing | Scrapped raw materials | Measure material waste |
| Production | Production output | Measure production volume |
| Production | Rejected batches | Measure production quality |
| Production | Rejection rate | Measure production efficiency |
| Warehouse | Finished product stock | Measure available inventory |
| Warehouse | Scrapped finished product | Measure product waste |
| E-commerce | Number of orders | Measure customer demand |
| E-commerce | Sales value | Measure revenue |
| E-commerce | Quantity sold | Measure product demand |
| Delivery | Average delivery time | Measure delivery performance |
| Delivery | Shipping costs | Measure delivery costs |
| B2B | Number of orders | Measure B2B demand |
| B2B | Sales value | Measure B2B revenue |
